# project-review-management

## Admin dashboard

The application creates an administrator account on first startup. The demo credentials are:

- Email: `admin@proreview.com`
- Password: `admin123`

Set `ADMIN_EMAIL` and `ADMIN_PASSWORD` in the environment before starting the backend to use different credentials. Sign in at `/login` to open the admin overview, which shows teacher and student totals, site activity, website details, and recent registrations.
